## Что такое JobSync

JobSync — это бесплатный локальный веб-сервис для управления поиском работы. Он работает на вашем компьютере по адресу `http://localhost:3737` и помогает:

- **Отслеживать** все вакансии, на которые вы откликнулись (включая hh.ru)
- **Автоматически находить** новые вакансии через JSearch API (агрегатор Google Jobs, Indeed, LinkedIn и др.)
- **Анализировать с помощью AI** соответствие вашего резюме конкретным вакансиям
- **Получать рекомендации AI** по улучшению резюме
- **Организовывать** заметки, теги навыков, вопросы к собеседованиям
- **Вести аналитику** поиска работы через дашборд

> **Важно:** JobSync не имеет прямой интеграции с API hh.ru. Вакансии с hh.ru добавляются вручную (через копирование ссылки и описания). Автоматический поиск работает через JSearch API и покрывает международные площадки. Далее в инструкции описаны оба подхода.

## Первый запуск и регистрация

### Доступ к приложению

Откройте браузер и перейдите по адресу:

```
http://localhost:3737
```

### Создание аккаунта

1. На экране входа нажмите ссылку для регистрации
2. Укажите **email** и **пароль** (минимум 6 символов)
3. Нажмите **Sign Up**
4. Система автоматически перенаправит вас на дашборд

> Данные хранятся локально в SQLite-базе на вашем компьютере. Ничего не отправляется на внешние серверы (кроме запросов к AI-провайдерам, если вы их настроите).

## Настройка AI-провайдера

AI нужен для двух ключевых функций: **анализа резюме** и **оценки совместимости с вакансией**. Без AI вы можете использовать JobSync как трекер вакансий, но не сможете получать интеллектуальные рекомендации.

### Шаг 1: Перейдите в Settings

В боковом меню нажмите **Settings**.

### Шаг 2: Настройте API-ключи (вкладка API Keys)

Выберите один из провайдеров:

| Провайдер | Стоимость | Что нужно | Лучше всего для |
|-----------|-----------|-----------|-----------------|
| **Ollama** | Бесплатно | Локальная установка Ollama | Полная приватность, нет расходов |
| **OpenAI** | Платно | API-ключ (sk-...) | Лучшее качество анализа |
| **DeepSeek** | Дёшево | API-ключ | Хороший баланс цена/качество |

#### Вариант А: Ollama (бесплатно, локально)

1. Установите [Ollama](https://ollama.ai) на ваш компьютер
2. Скачайте модель: `ollama pull llama3.2`
3. Убедитесь, что Ollama запущена (порт 11434)
4. В Settings → API Keys → Ollama укажите URL: `http://127.0.0.1:11434`
5. Нажмите **Verify & Save**

#### Вариант Б: OpenAI

1. Получите API-ключ на [platform.openai.com](https://platform.openai.com)
2. В Settings → API Keys → OpenAI введите ключ
3. Нажмите **Verify & Save**

#### Вариант В: DeepSeek

1. Получите API-ключ на [platform.deepseek.com](https://platform.deepseek.com)
2. В Settings → API Keys → DeepSeek введите ключ
3. Нажмите **Verify & Save**

### Шаг 3: Выберите AI-провайдер (вкладка AI Provider)

1. Перейдите на вкладку **AI Provider**
2. Выберите провайдер, ключ которого вы только что настроили
3. Выберите модель (рекомендуемые: `llama3.2` для Ollama, `gpt-4o-mini` для OpenAI, `deepseek-chat` для DeepSeek)
4. Сохраните настройки

### Шаг 4 (опционально): RapidAPI для автоматического поиска

Если вам нужен автоматический поиск вакансий:

1. Зарегистрируйтесь на [rapidapi.com](https://rapidapi.com)
2. Подпишитесь на [JSearch API](https://rapidapi.com/letscrape-6bRBa3QguO5/api/jsearch) (есть бесплатный план)
3. В Settings → API Keys → RapidAPI введите ключ
4. Нажмите **Verify & Save**

## Создание резюме в системе

Резюме необходимо для AI-анализа совместимости с вакансиями и для автоматического поиска.

### Шаг 1: Перейдите в Profile

В боковом меню нажмите **Profile**.

### Шаг 2: Создайте новое резюме

1. Нажмите **Create Resume**
2. Введите название (например, «Python-разработчик» или «Менеджер проектов»)
3. Сохраните

### Шаг 3: Заполните разделы

Откройте созданное резюме и последовательно заполните:

#### Контактная информация
- Имя, фамилия
- Заголовок (например, «Senior Backend Developer»)
- Email, телефон

#### Summary (Краткое описание)
Напишите 3-5 предложений о вашем профессиональном опыте и ключевых компетенциях. Пишите на том же языке, на котором ищете работу.

**Пример:**
> Опытный Python-разработчик с 5+ годами опыта в разработке высоконагруженных сервисов. Специализация: микросервисная архитектура, FastAPI, PostgreSQL, Redis. Опыт руководства командой из 4 человек.

#### Experience (Опыт работы)
Для каждого места работы укажите:
- Компания
- Должность
- Локация
- Даты работы
- Описание обязанностей и достижений

> **Совет для hh.ru:** Скопируйте описание опыта из вашего резюме на hh.ru, чтобы AI-анализ был максимально точным.

#### Education (Образование)
- Учебное заведение
- Степень/квалификация
- Специальность
- Даты обучения

### Шаг 4 (опционально): Загрузите файл резюме

Вы можете загрузить PDF-файл вашего резюме для хранения.

> **Совет:** Создайте несколько резюме для разных направлений поиска. Например, одно для «Backend-разработчик», другое для «Full-stack разработчик». Это повысит точность AI-матчинга.

## Ручное добавление вакансий с hh.ru

Это основной способ работы с hh.ru в JobSync. Вы находите вакансию на hh.ru и вносите её в систему для отслеживания и AI-анализа.

### Пошаговый процесс

#### 1. Найдите вакансию на hh.ru

Откройте [hh.ru](https://hh.ru), используйте поиск по нужным критериям.

#### 2. Скопируйте данные вакансии

Подготовьте:
- **Ссылку** на вакансию (из адресной строки, например `https://hh.ru/vacancy/12345678`)
- **Название должности**
- **Название компании**
- **Описание вакансии** (полный текст с требованиями и обязанностями)

#### 3. Добавьте вакансию в JobSync

1. Перейдите в **My Jobs** в боковом меню
2. Нажмите кнопку **New Job** (справа вверху)
3. Заполните форму:

| Поле | Что указать | Пример |
|------|-------------|--------|
| **Job URL** | Ссылка с hh.ru | `https://hh.ru/vacancy/12345678` |
| **Job Title** | Название должности | Python Developer |
| **Company** | Название компании | Яндекс |
| **Job Location** | Город | Москва |
| **Job Type** | Тип занятости | Full-time / Part-time / Contract |
| **Job Source** | Откуда вакансия | hh.ru (создайте при первом использовании) |
| **Status** | Текущий статус | Draft / Applied |
| **Salary Range** | Диапазон зарплаты | Выберите подходящий |
| **Resume** | Какое резюме используете | Выберите из списка |
| **Skills** | Ключевые навыки | Python, FastAPI, PostgreSQL |
| **Job Description** | Описание вакансии | Скопируйте полный текст с hh.ru |

4. Если вы уже откликнулись — включите тумблер **Applied** и укажите дату отклика
5. Нажмите **Save**

#### 4. Используйте AI-анализ

После сохранения вакансии вы можете запустить AI-оценку совместимости (см. раздел [AI-анализ: совместимость с вакансией](#ai-анализ-совместимость-с-вакансией)).

> **Рабочий совет:** Заведите привычку — при каждом отклике на hh.ru сразу добавлять вакансию в JobSync. Это займёт 1-2 минуты, но позволит вести полную аналитику поиска.

## Автоматический поиск вакансий

> **Примечание:** Автоматический поиск работает через JSearch API (агрегатор Google Jobs), а не напрямую через hh.ru. Он лучше всего подходит для поиска вакансий на международных площадках (Indeed, LinkedIn, Glassdoor и др.). Для российского рынка рекомендуется комбинировать с ручным поиском на hh.ru.

### Предварительные требования

- Настроен AI-провайдер (Ollama/OpenAI/DeepSeek)
- Создано резюме в системе
- Настроен RapidAPI ключ (Settings → API Keys → RapidAPI)

### Создание автоматизации

1. Перейдите в **Automations** в боковом меню
2. Нажмите **Create Automation**
3. Пройдите пошаговый мастер:

#### Шаг 1: Basics (Основное)
- **Automation Name** — понятное название, например «Python вакансии Москва»
- **Job Board** — выберите JSearch (Google Jobs)

#### Шаг 2: Search (Поисковый запрос)
- **Search Keywords** — ключевые слова для поиска. Пишите на английском для международных вакансий.
  - Примеры: `Python Developer`, `React Frontend`, `DevOps Engineer`
- **Location** — местоположение
  - Примеры: `Moscow`, `Remote`, `Berlin, Germany`

#### Шаг 3: Resume (Резюме)
- Выберите резюме, относительно которого будет оцениваться совместимость

#### Шаг 4: Matching (Порог совместимости)
- **Match Threshold** — минимальный процент совпадения (по умолчанию 80%)
  - 80-100% — только очень точные совпадения
  - 60-80% — больше вакансий, включая смежные
  - 40-60% — широкий поиск, много вариантов

#### Шаг 5: Schedule (Расписание)
- **Daily Run Time** — время ежедневного запуска (час, по серверному времени)
  - Рекомендуется 08:00 или 09:00

#### Шаг 6: Review (Проверка)
- Проверьте все настройки и нажмите **Create Automation**

### Управление автоматизациями

В списке автоматизаций вы можете:
- **Запустить вручную** — кнопка Run (не чаще 5 раз в час)
- **Приостановить/Возобновить** — переключить статус Active/Paused
- **Редактировать** — изменить параметры поиска
- **Просматривать логи** — детальная информация о каждом запуске
- **Просматривать найденные вакансии** — список вакансий, прошедших AI-фильтр

### Как работает автоматический поиск

1. В назначенное время система делает запрос к JSearch API
2. Получает список вакансий по вашим ключевым словам и локации
3. Удаляет дубликаты (вакансии, которые вы уже видели)
4. Для каждой новой вакансии (максимум 10 за запуск):
   - Отправляет описание вакансии и ваше резюме в AI
   - AI оценивает совместимость в процентах
   - Если оценка выше порога — вакансия сохраняется
5. Найденные вакансии появляются в разделе Automations → Discovered Jobs

## AI-анализ: оценка резюме

AI может проанализировать ваше резюме и дать рекомендации по улучшению.

### Как запустить

1. Перейдите в **Profile**
2. Откройте нужное резюме
3. Нажмите кнопку **Resume Review** (или аналогичную)
4. Дождитесь завершения анализа (может занять 10-30 секунд)

### Что вы получите

- **Общий балл качества** (0-100%)
- **Анализ навыков** — какие навыки указаны, каких не хватает
- **Оценка опыта** — как описан ваш опыт
- **Оптимизация ключевых слов** — какие слова стоит добавить
- **Рекомендации по улучшению** — конкретные советы

> **Совет для hh.ru:** Используйте рекомендации AI для улучшения вашего резюме на hh.ru. Обратите внимание на предложенные ключевые слова — они повышают видимость резюме в поиске работодателей.

## AI-анализ: совместимость с вакансией

Это самая полезная функция при работе с вакансиями hh.ru. AI сравнивает ваше резюме с описанием конкретной вакансии.

### Как запустить

1. Перейдите в **My Jobs**
2. Откройте карточку вакансии (нажмите на строку в таблице)
3. Нажмите кнопку **Job Match** (или аналогичную)
4. Выберите резюме для сравнения
5. Дождитесь результата

### Что вы получите

- **Match Score** (0-100%) — общая совместимость
- **Совпадающие навыки** — какие из ваших навыков соответствуют требованиям
- **Недостающие навыки** — чего не хватает
- **Релевантный опыт** — какой ваш опыт подходит
- **Рекомендации по адаптации** — как подстроить резюме под конкретную вакансию

### Как интерпретировать результат

| Балл | Значение | Рекомендация |
|------|----------|--------------|
| 85-100% | Отличное совпадение | Обязательно откликайтесь |
| 70-84% | Хорошее совпадение | Стоит откликнуться, подкорректировав сопроводительное письмо |
| 50-69% | Частичное совпадение | Откликайтесь, если готовы подтянуть недостающие навыки |
| 30-49% | Слабое совпадение | Вакансия далека от вашего профиля |
| 0-29% | Не подходит | Лучше поискать другие варианты |

> **Совет:** Перед откликом на hh.ru запустите AI Job Match. Если балл ниже 50%, вы потратите отклик (на hh.ru они ограничены) на вакансию с низкими шансами.

## Отслеживание откликов и статусов

### Статусы вакансий

JobSync поддерживает следующие статусы:

| Статус | Когда использовать |
|--------|-------------------|
| **Draft** | Нашли вакансию, ещё не откликались |
| **Applied** | Отправили отклик на hh.ru |
| **Interview** | Получили приглашение на собеседование |
| **Offer** | Получили предложение о работе |
| **Rejected** | Получили отказ |
| **Expired** | Вакансия закрыта/истекла |
| **Archived** | Вакансия больше не актуальна для вас |

### Рабочий процесс с hh.ru

1. **Нашли вакансию** → добавьте в JobSync со статусом **Draft**
2. **Запустили AI Job Match** → оценили совместимость
3. **Откликнулись на hh.ru** → смените статус на **Applied**, включите тумблер Applied, укажите дату
4. **Получили приглашение** → смените статус на **Interview**
5. **Прошли собеседование** → добавьте заметку с впечатлениями
6. **Получили ответ** → смените статус на **Offer** или **Rejected**

### Фильтрация и поиск

В **My Jobs** вы можете:
- Фильтровать по статусу (например, показать только Applied)
- Искать по названию должности или компании
- Сортировать по дате
- Фильтровать по тегам навыков

## Заметки, теги и вопросы

### Заметки к вакансиям

Для каждой вакансии можно вести заметки:

1. Откройте вакансию в режиме редактирования
2. В нижней части формы найдите раздел **Notes**
3. Добавьте заметку

**Что полезно записывать:**
- Имя рекрутера/HR с hh.ru
- Впечатления от общения
- Задачи из тестового задания
- Вопросы, которые задали на собеседовании
- Условия оффера

### Теги навыков

Теги помогают категоризировать вакансии по навыкам:

1. При добавлении/редактировании вакансии найдите поле **Add Skill**
2. Начните вводить навык — система предложит существующие теги
3. Выберите существующий или создайте новый

**Примеры тегов:** `Python`, `FastAPI`, `PostgreSQL`, `Docker`, `React`, `TypeScript`

Теги можно управлять централизованно в **Administration → Tags**.

### Банк вопросов

Раздел **Questions** позволяет собирать вопросы для подготовки к собеседованиям:

1. Перейдите в **Questions** в боковом меню
2. Нажмите **Add Question**
3. Введите вопрос и привяжите теги

**Примеры вопросов для подготовки:**
- «Расскажите о GIL в Python и способах обхода»
- «Чем отличается горизонтальное масштабирование от вертикального?»
- «Опишите архитектуру последнего проекта»

> **Совет:** После каждого собеседования записывайте вопросы, которые вам задали. Это поможет подготовиться к следующим интервью.

## Задачи и активности

### Задачи (Tasks)

Используйте задачи для планирования шагов поиска работы:

1. Перейдите в **Tasks**
2. Нажмите **Add Task**
3. Укажите:
   - Название задачи
   - Приоритет (Low / Medium / High)
   - Дедлайн
4. Отмечайте выполненные задачи

**Примеры задач:**
- «Обновить резюме на hh.ru»
- «Подготовить портфолио на GitHub»
- «Выполнить тестовое задание для Компании X»
- «Подготовиться к собеседованию в Компании Y»

### Активности (Activities)

Отслеживайте время, потраченное на поиск работы:

1. Перейдите в **Activities**
2. Добавьте активность:
   - Тип: звонок, email, собеседование и др.
   - Длительность (до 8 часов)
   - Привязка к задаче (опционально)

**Примеры активностей:**
- «Собеседование в Яндексе — 1.5 часа»
- «Отклики на hh.ru — 2 часа»
- «Тестовое задание — 4 часа»

## Дашборд и аналитика

Дашборд (главная страница после входа) показывает:

- **Общее количество вакансий** по статусам
- **График активности за неделю** — сколько времени вы тратите на поиск
- **Источники вакансий** — откуда приходят вакансии (hh.ru, LinkedIn и др.)
- **Распределение по статусам** — визуальная разбивка
- **Диапазоны зарплат** — статистика по зарплатам
- **Общее время активностей** за неделю

> Дашборд помогает отслеживать прогресс и поддерживать мотивацию. Рекомендуется проверять его ежедневно.

---

## Экспорт данных

Вы можете экспортировать все вакансии в CSV-файл:

1. Перейдите в **My Jobs**
2. Нажмите кнопку **Export** (значок загрузки)
3. Файл скачается автоматически

CSV можно открыть в Excel/Google Sheets для дополнительного анализа.

## Рекомендуемый рабочий процесс

### Ежедневный (15-20 минут)

1. **Утро:** Откройте дашборд JobSync, проверьте статус задач
2. **Поиск на hh.ru:** Просмотрите новые вакансии по сохранённым поискам
3. **Для каждой интересной вакансии:**
   - Добавьте в JobSync → New Job
   - Вставьте ссылку и описание
   - Запустите AI Job Match
   - Если балл > 60% — откликнитесь на hh.ru
   - Обновите статус на Applied
4. **Вечер:** Проверьте ответы от работодателей на hh.ru, обновите статусы

### Еженедельный (30 минут)

1. Проверьте дашборд — сколько откликов, собеседований, отказов
2. Обновите резюме, если AI выявил слабые места
3. Запустите AI Resume Review для обновлённого резюме
4. Просмотрите найденные автоматизацией вакансии (если настроена)
5. Обновите банк вопросов после собеседований

### При подготовке к собеседованию

1. Откройте вакансию в JobSync
2. Перечитайте описание вакансии и AI-анализ совместимости
3. Обратите внимание на «недостающие навыки» — подготовьте ответы, как вы компенсируете пробелы
4. Просмотрите банк вопросов по тегам, совпадающим с требованиями вакансии
5. После собеседования — добавьте заметку с вопросами и впечатлениями

## Часто задаваемые вопросы

### Можно ли автоматически парсить вакансии с hh.ru?

Нет, прямой интеграции с hh.ru API нет. Вакансии с hh.ru добавляются вручную. Автоматический поиск работает через JSearch API и покрывает Indeed, LinkedIn, Glassdoor, ZipRecruiter и другие площадки.

### Бесплатен ли сервис?

Сам JobSync полностью бесплатен. Дополнительные расходы зависят от выбранных интеграций:
- **Ollama (AI)** — бесплатно, работает локально
- **OpenAI (AI)** — платно, ~$0.01-0.03 за один анализ вакансии
- **DeepSeek (AI)** — очень дёшево, ~$0.001-0.005 за анализ
- **JSearch/RapidAPI** — есть бесплатный план (500 запросов/месяц)

### Безопасны ли мои данные?

Да. Все данные хранятся локально на вашем компьютере в SQLite-базе. API-ключи шифруются алгоритмом AES-256-GCM. На внешние серверы отправляются только запросы к AI-провайдерам (если настроены) и к JSearch API (если используете автоматизацию).

### Что делать, если AI-анализ не работает?

1. Проверьте, что AI-провайдер настроен (Settings → AI Provider)
2. Проверьте API-ключ (Settings → API Keys — должен быть зелёный значок)
3. Для Ollama — убедитесь, что сервис запущен: `curl http://localhost:11434/api/tags`
4. Проверьте логи автоматизации (Automations → Logs) на ошибки

### Как создать источник «hh.ru»?

При добавлении первой вакансии с hh.ru в поле **Job Source** начните вводить «hh.ru». Система предложит создать новый источник — подтвердите. После этого «hh.ru» будет доступен в списке источников для всех последующих вакансий.

### Можно ли использовать на телефоне?

JobSync — это веб-приложение с адаптивным дизайном. Вы можете открыть `http://localhost:3737` в браузере телефона, если телефон и компьютер в одной сети (замените localhost на IP вашего компьютера).

### Как обновить приложение?

Если установлено через Docker:
```bash
docker compose pull
docker compose up -d
```

Если установлено локально:
```bash
git pull
npm install
npx prisma migrate dev
npm run build
```
